## Important for production
This project is a front-end starter. Do **not** rely on JavaScript alone to protect paid files or verify payments.

For a real launch, connect:
1. Authentication (Firebase Auth, Supabase Auth, or a custom server).
2. A database for users, subscriptions, reviews and resource metadata.
3. Secure file storage with access rules.
4. A payment/Mobile Money integration that can verify successful payments server-side.
5. Admin authentication and role-based permissions.
6. Server-side subscription checks before a PDF/file download.
7. Upload validation, malware scanning and copyright/ownership checks.
